# IAU

iShares Gold Trust creation/redemption arbitrage desk — cloned from the ARKB template.

- App: [`IAU-arb/node/public`](IAU-arb/node/public) (static, deployed to Azure Static Web Apps)
- Underlying: Gold (GC=F)
- Sponsor: BlackRock (iShares Delaware Trust Sponsor LLC) · Custodian: JPMorgan Chase Bank, N.A., London

## Local
```bash
cd IAU-arb/node
npm install
npm run dashboard   # dry-run web UI
```
